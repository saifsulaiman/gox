# GOX v0.4 Implementation Report

## Outcome

GOX v0.4 implements **Region and Arena Inference**, enabling automatic, deterministic memory management for allocations whose lifetime exceeds an individual function frame but remains bounded by an identifiable program lifecycle.

In v0.3, any allocation that outlived its creating function frame was forced to fall back to tracing GC. GOX v0.4 proves the lifetime boundaries of these multi-frame and cyclic objects, assigning them to scoped arenas that can be allocated via fast bump allocation and reclaimed or reset in bulk ($O(1)$) with zero garbage collector involvement.

On the `examples/basic` application, proven tracing-GC reduction increased from **25.0%** in v0.3 to **50.0%** in v0.4.

---

## Delivered Capabilities

### 1. Internal Region IR (`internal/region/ir.go`)
- Developed internal region intermediate representation modeling five distinct scopes:
  * `ScopeFunction`: Function-local region for batch processing and temporary cyclic graphs.
  * `ScopeCaller`: Caller-owned region for constructor returns and factory patterns.
  * `ScopeLexical`: Block and loop-scoped regions reset or destroyed per iteration.
  * `ScopeRequest`: Dynamic request/transaction lifecycle regions.
  * `ScopeNested`: Child sub-regions nested inside parent arenas.
- Modeled formal IR operations: `region.create`, `region.alloc`, `region.borrow`, `region.escape`, `region.reset`, `region.destroy`.
- Formulated and verified the **Outlive-Ordering Theorem**: references can only point from shorter-lived to longer-lived regions, preventing dangling pointer vulnerabilities.

### 2. High-Performance Region Runtime (`internal/runtime/arena.go`)
- Implemented a zero-lock, goroutine-confined chunk-based bump allocator.
- Default 64 KB contiguous chunks with automatic pointer-alignment padding.
- `Alloc[T](*Arena)`: Typed zero-initialization bump allocation.
- `AllocSlice[T](*Arena, len, cap)`: Typed slice allocation backed by arena memory.
- `Reset()`: $O(1)$ pointer reset preserving underlying OS chunks for instant reuse in loops or request handlers.
- `Free()`: Releases chunks back to the OS or allocator pool.
- Validated via comprehensive unit tests and benchmarks in `internal/runtime/arena_test.go`.

### 3. Region Proof & Inference Engine (`internal/analyzer/regionproof.go`)
- Evaluates non-stack allocations against sound region lifetime invariants.
- Identifies caller-owned regions by tracing interprocedural returns across call graphs.
- Safely handles cyclic data structures (e.g. doubly-linked lists, AST nodes, graph structures): because the entire arena is reclaimed in bulk, cyclic structures inside a region do not leak and require no cycle detectors.
- Strictly rejects any candidate exhibiting escape hazards (global variables, concurrent goroutines, channels, unsafe pointers, reflection, open-world dispatch).

### 4. Memory Strategy Decision Engine Integration (`internal/analyzer/strategy.go`)
- Integrated `regionProofEngine` into `strategyEngine`.
- Two-tier proven promotion:
  1. Try Stack Proof $\to$ if proven, assign `StrategyStack` (`PROVEN`).
  2. Try Region Proof $\to$ if proven, assign `StrategyRegion` (`PROVEN`).
  3. Otherwise, safely fall back to `StrategyTracingFallback` (`PROBABLE` or `UNPROVEN`).
- Tracks `ProvenRegionCount` and updates `ProvenGCReduction` percentage to reflect both stack and region eliminations.

### 5. CLI and Report Extensions
- Bumped version to `0.4.0` in `cmd/gox/main.go` and `internal/analyzer/analyzer.go`.
- Added region scope, owner, and destroy point formatting to `internal/report/strategy.go`.
- Full JSON serialization of `RegionInfo`.

### 6. Region Adversarial & Safety Test Suite (`internal/analyzer/region_adversarial_test.go`)
- Validated caller-owned region promotion (`makePayload`).
- Validated function-local cyclic graph region promotion (`CyclicGraphProcessing`).
- Verified that allocations escaping via globals, goroutines, channels, `unsafe.Pointer`, or reflection are strictly rejected from region promotion.

### 7. Realistic Workload Benchmarks (`internal/analyzer/bench_region_test.go`)
- HTTP request-scoped workload simulation.
- Parser AST construction and bulk destruction simulation.
- Region analysis latency and throughput benchmarking.

## Invariants & Safety Guarantees

1. **Zero Annotations**: Ordinary Go source code remains 100% standard Go. No lifetime or region annotations are required.
2. **Outlive-Ordering Invariant**: No longer-lived region may hold a reference to an object in a shorter-lived region.
3. **Cycle Safety without Leaks**: Any cyclic graph contained within an arena is safely reclaimed in $O(1)$ upon arena reset/free.
4. **Conservative Fallback Priority**: Any allocation reaching global state, concurrent channels, or open-world boundaries remains under tracing GC.

## Roadmap to v0.5 (Ownership-Based Reclamation)

With Stack and Region placement active:
- **v0.5** will introduce **Deterministic Unique-Owner Destruction**: tracking unique ownership across assignments, function calls, and returns to insert deterministic deallocations at points of last use for unshared objects.
